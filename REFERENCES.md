# Inventário de referências do FrameNasa 0.2.0

Este arquivo registra materiais incorporados ao próprio framework. Dados e recursos utilizados por projetos criados com o FrameNasa devem ser registrados separadamente na documentação de cada projeto.

| Item | Origem | Licença ou condição | Uso |
|---|---|---|---|
| Código-fonte do FrameNasa | Contribuidores do repositório | Apache-2.0 | Framework completo |
| HTML, CSS e APIs Web utilizados | Padrões nativos da plataforma Web | Padrões abertos; nenhuma biblioteca copiada | Interface, arquivos locais e requisições configuráveis |
| Dados de demonstração | Criados para o FrameNasa | Apache-2.0 junto do repositório | Exemplos sintéticos em `data.js`, `scenario.js` e `examples/` |
| Codex da OpenAI | Ferramenta de assistência ao desenvolvimento | Serviço externo; nenhum código de SDK incorporado | Apoio na redação, implementação, revisão e testes |

## Dependências distribuídas

O projeto não possui dependências de runtime de terceiros e não inclui imagens, fontes, logotipos ou conjuntos de dados externos. Node.js é usado somente para servidor local, build e testes; não é redistribuído neste repositório.

## Como registrar um projeto derivado

Crie uma tabela contendo, no mínimo: recurso, autor ou organização, URL de origem, versão ou data de acesso, licença, uso no projeto e alterações realizadas. Identifique também as ferramentas de IA usadas. Não atribua ao FrameNasa a licença de dados importados: a licença de cada conjunto continua sendo definida pelo seu provedor.
